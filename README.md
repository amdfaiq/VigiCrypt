# VigiCrypt
Website statis yang dibangun untuk mengimplementasikan algoritma enkripsi dan dekripsi Vigenère Cipher, salah satu metode kriptografi klasik yang menggunakan kunci berbasis teks untuk mengamankan pesan.

**Tech stack**:
HTML, CSS, Javascript

**Features**:
1. Enkripsi
Fitur enkripsi pada web ini menggunakan algoritma Vigenère Cipher, yang merupakan teknik kriptografi klasik yang memanfaatkan pergeseran karakter dalam pesan berdasarkan kunci yang diberikan. Pengguna dapat mengonversi teks biasa (plaintext) menjadi teks terenkripsi (ciphertext).

2. Dekripsi
Fitur dekripsi bertujuan untuk mengembalikan ciphertext yang telah dienkripsi kembali ke bentuk teks biasa (plaintext). Proses dekripsi menggunakan algoritma Vigenère Cipher yang sama dengan enkripsi, namun arah pergeseran karakter dibalik. 

3. Suggest Key 
Fungsi suggest key bertujuan untuk menghasilkan rekomendasi kunci otomatis berdasarkan teks input dan tanggal/waktu saat ini.

4. History 
Fungsi history bertujuan untuk menyimpan dan menampilkan riwayat hasil enkripsi dan dekripsi yang telah dilakukan. Pengguna juga dapat menghapus history yang ada.

5. Dark Mode 
Fitur dark mode memungkinkan pengguna untuk beralih antara tema terang (light mode) dan tema gelap (dark mode) untuk meningkatkan kenyamanan visual, terutama dalam kondisi pencahayaan rendah.
